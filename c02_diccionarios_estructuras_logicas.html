Creación, acceso y modificación de diccionarios

Los diccionarios son estructuras de datos que permiten almacenar información en pares de clave y valor, facilitando la organización y recuperación eficiente de datos. A diferencia de las listas, donde los elementos se acceden mediante posiciones numéricas, los diccionarios permiten acceder a la información a través de identificadores específicos (claves), lo que los convierte en herramientas especialmente útiles para representar datos estructurados y relaciones entre elementos. En Python, los diccionarios son ampliamente utilizados en tareas de análisis y ciencia de datos, ya que permiten configurar parámetros eficientemente y modelar información compleja dada su flexibilidad y rapidez de acceso.

Definición y uso de funciones para automatización de procesos

Las funciones constituyen bloques de código reutilizables diseñados para ejecutar tareas específicas dentro de un programa. Su principal objetivo es modularizar la solución de un problema, permitiendo dividir procesos complejos en partes más pequeñas, organizadas y fáciles de mantener. Mediante el uso de funciones, es posible reducir la repetición de código, mejorar la legibilidad de los programas y facilitar la detección de errores. En Python, las funciones pueden recibir parámetros de entrada y retornar resultados, lo que favorece la creación de programas más dinámicos, reutilizables y escalables. Vale mencionar que su uso te permitirá desarrollar procesos de manera más eficiente en distintos ámbitos de la preparación, análisis y modelamiento de datos.

Creación y uso de bucles o estructuras repetitivas

Los bucles, también conocidos como estructuras repetitivas, permiten ejecutar un conjunto de instrucciones múltiples veces de manera automática. Estas estructuras son fundamentales cuando se requiere procesar colecciones de datos, realizar tareas iterativas o automatizar operaciones repetitivas. El uso adecuado de bucles contribuye significativamente a la eficiencia y simplicidad de un programa, evitando la necesidad de escribir instrucciones redundantes. En Python, los bucles más utilizados son los llamados for y while, cada uno orientado a diferentes tipos de procesos iterativos. Por una parte los bucles for facilitan el realizar tareas específicas en cada uno de los elementos de objetos iterables (p. ej., listas o diccionarios); mientras que los bucles while se especializan en repetir procedimientos mientras se cumpla una condición específica.

Creación y uso de estructuras condicionales

Las estructuras condicionales permiten que un programa tome decisiones y ejecute diferentes acciones según se cumplan determinadas condiciones lógicas. Este mecanismo constituye la base del control de flujo en programación, ya que posibilita adaptar el comportamiento del programa frente a distintos escenarios o entradas de información. A través de condicionales, un algoritmo puede evaluar expresiones lógicas y seleccionar la ruta de ejecución más adecuada. En Python, las instrucciones if, elif y else proporcionan una forma clara y flexible de implementar procesos de decisión dentro de un programa.

Ejercicio 1

Recorre el diccionario de clientes con un bucle y extrae en una lista clientes_jovenes todos los nombres de los clientes que tengan menos de 45 años.

clientes_jovenes = []

# Definir bucle for para recorrer el diccionario
for nombre in cliente_dicc.keys():

    edad_cliente = cliente_dicc[nombre]

    # Guardar nombre en lista si cumple con la condición mediante un if
    if edad_cliente < 45:
        clientes_jovenes.append(nombre)

Escribe una función llamada promedios que calcule las principales medidas de centralidad de dos números cualesquiera y devuelva los resultados a modo de diccionario. Para esto considera los siguientes estadísticos:

  • Media aritmética (\(\bar{x}_a\)):

\[ \bar{x}_a = \frac{x_1 + x_2}{2} \]

  • Media geométrica (\(\bar{x}_g\)):

\[ \bar{x}_g = \sqrt{|x_1 \times x_2|} \]

  • Media armónica (\(\bar{x}_h\)):

\[ \bar{x}_h = \frac{2}{\frac{1}{x_1} + \frac{1}{x_2}} = \frac{2\times x_1 \times x_2}{x_1 + x_2} \]

NotaSolución 
def promedios(x_1, x_2):
    med_a = (x_1 + x_2) / 2
    med_g = abs(x_1 * x_2) ** (0.5)
    med_h = (2 * x_1 * x_2) / (x_1 + x_2)
    dicc = {
        "media aritmética": med_a,
        "media geométrica": med_g,
        "media armónica": med_h
    }
    return dicc

def varianza(x_1, x_2):

    return var

def es_bisiesto(a):
    bisiesto = True

    if a % 4 == 0:

Ejercicio 2

Escribe una función es_primo que reciba como entrada un número natural cualquiera y devuelva si el número es primo o compuesto. Vale indicar que un número primo es aquel que solamente es divisible por 1 y por sí mismo, por ejemplo el 7, 11 o 13. Solamente ten cuidado puesto que el número 1 NO es primo.

NotaSolución 
def es_primo(n):
    if n == 1:
        primo = False
    elif n == 2:
        primo = True
    else:
        primo = True
        for d in range(2, n):
            if n % d == 0:
                primo = False
                break  # El comando break permite detener el bucle sin necesidad de recorrer todas las opciones

    return primo

La sucesión de Fibonacci es un conjunto de números naturales muy famoso que deberías conocer al menos por cultura general. En esta sucesión se cumple que el número \(a\) en la posición \(i\) está dado por \(a_i = a_{i-1} + a_{i-2}\), con \(a_1 = 0\) y \(a_2 = 1\). En este sentido, los primeros elementos de esta sucesión son:

\[ 0, 1, 1, 2, 3, 5, 8, 13, \ldots \]

Utiliza funciones y condicionales para calcular cuál es el número 40 de Fibonacci.

NotaSolución 
# Definir función
def fibonacci(n):
    a1 = 0
    a2 = 1
    if n == 1:
        resultado = a1
    elif n == 2:
        resultado = a2
    else:
        resultado = fibonacci(n - 1) + fibonacci(n - 2)
    return resultado

# Calcular y mostrar el número 40 de Fibonacci
print(f"Número 40 de Fibonacci: {fibonacci(40):,.0f}")

La combinatoria es una operación matemática que permite estimar cuántos grupos posibles de \(k\) elementos se pueden crear a partir de un conjunto de tamaño \(n\). Esta operación se define por

\[ \binom{n}{k} = \frac{n!}{k!(n-k)!} \]

donde \(n! = n(n-1)(n-2)\cdots 1\) es el factorial de \(n\), y \(k! = k(k-1)(k-2)\cdots 1\) es el factorial de \(k\). A partir de esta operación es factible, por ejemplo, saber que existen 6 posibles grupos de 2 elementos de un conjunto de 4, ya que

\[ \binom{4}{2} = \frac{4!}{2!(4-2)!} = \frac{4 \times 3 \times 2 \times 1}{2 \times 1 \times 2 \times 1} = 3 \times 2 = 6\]

Una propiedad interesante asociada a la combinatoria es la denominada Identidad de Pascal, la cual afirma que:

\[ \binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}\]

A partir de esta identidad crea una función que tome dos valores \(n\) y \(k\) cualesquiera y devuelva el valor de la combinatoria correspondiente. Para esto considera las siguientes propiedades adicionales de la operación:

  • \(\binom{n}{0} = 1\)
  • \(\binom{n}{k} = 1\) para \(n = k\)
  • \(\binom{n}{k} = 0\) para \(k > n\)

Verifica tu función comprobando que \(\binom{4}{2} = 6\).

NotaSolución 
# Definir función
def combinatoria(n, k):
    if k == 0:
        return 1
    if k == n:
        return 1
    if k > n:
        return 0
    return combinatoria(n - 1, k - 1) + combinatoria(n - 1, k)

# Comprobar función
combinatoria(4, 2)
6

NotaDistribuciones estadísticas y combinatoria

Los valores que toma una variable presentan un comportamiento que puede describirse formalmente mediante lo que se conoce como distribución estadística. Esta distribución refleja la forma en que se organizan y se presentan los datos, y depende de las características particulares de la variable que se está estudiando. Por ello, puede adoptar distintas formas según el fenómeno observado.

Una manera de comprender cómo se generan algunas de estas distribuciones es a través de la combinatoria, que permite estudiar las distintas posibilidades de ocurrencia de determinados resultados. A continuación, se presentan algunas distribuciones estadísticas que siguen este principio:

  • Binomial.
  • Multinomial.
  • Binomial negativa.
  • Hipergeométrica.
  • Beta.
  • Gamma.
