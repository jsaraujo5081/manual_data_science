I. Fundamentos de Programación con Python

En los siguientes ejercicios se propone una introducción práctica a los fundamentos de programación utilizando el lenguaje Python, uno de los entornos más utilizados actualmente en áreas como ciencia de datos, automatización de procesos, desarrollo de software y análisis computacional. El propósito principal de estas actividades es fortalecer la comprensión de conceptos esenciales de programación mediante la resolución de problemas sencillos y progresivos, promoviendo además el desarrollo del pensamiento lógico y estructurado.

  • Creación, acceso y modificación de listas.

El dominio de estos temas constituye una etapa inicial indispensable dentro del aprendizaje de la programación, ya que permite comprender cómo representar información, procesarla y controlar el comportamiento de un programa frente a diferentes escenarios. De igual manera, estas actividades buscan fomentar buenas prácticas de escritura de código, claridad en la lógica de solución y capacidad de análisis computacional, habilidades fundamentales para tu estudio posterior de ciencia de datos.

Manejo de variables y almacenamiento de información

Las variables constituyen uno de los elementos más importantes dentro de la programación, ya que permiten almacenar y manipular información durante la ejecución de un programa. A través de ellas es posible representar datos numéricos, textos, valores lógicos y otros tipos de información necesarios para resolver problemas computacionales. En Python, las variables se caracterizan por su flexibilidad y facilidad de uso, permitiéndonos asignar valores de manera dinámica y reutilizarlos posteriormente en operaciones, cálculos y procesos lógicos.

Ejercicio 1

Calcula el promedio (media aritmética) de edades en una nueva variable llamada prom_ages.

prom_ages = (john_age + brother_age) / 2

Muestra en pantalla la siguiente frase:

John tiene john_age años y su hermano tiene brother_age. La diferencia de edad entre ellos es diff_ages y su promedio es prom_ages.

Prueba imprimir esto con al menos una de las siguientes formas:

  • Secuencia de variables.
  • f-string.
  • format string.
# Imprimir mediante secuencias de variables

f-string es la forma más recomendada para imprimir mensajes que contienen variables debido a su sintaxis concisa y directa. Además, como veremos más adelante, con f-strings es factible dar formato a variables de tipo numérico de manera sencilla.

TypeError: can only concatenate str (not "float") to str

TypeError es la denominación que Python da a los errores asociados al tipo de variable, y lo que aquí se nos indica es que no es posible concatenar (sumar) valores flotantes con cadenas de texto. En la siguiente sección vamos a profundizar más en los errores y en cómo gestionarlos.

Visto esto, ajusta el código existente añadiendo una nueva línea en la que se convierta la variable john_bitcoins a flotante con la función float.

john_bitcoins = john_bitcoins + 1.3
print(f"{john_bitcoins:.2f} BTC")
3.75 BTC

Ahora convierte los bitcoins de John a entero con la función int, guarda este resultado en una nueva variable e imprímelo.

john_bitcoins_int = int(john_bitcoins)
print(f"{john_bitcoins_int:.2f} BTC")
3.00 BTC

Haz una nueva conversión, pero ahora usando la función round, e imprime la variable resultante.

john_bitcoins_round = round(john_bitcoins)
print(f"{john_bitcoins_round:.2f} BTC")
4.00 BTC

Como puedes evidenciar, las funciones int y round permiten aproximar un valor flotante a uno entero. Sin embargo, no funcionan exactamente igual:

  • La primera devuelve solamente la parte entera del valor original; es decir, trunca los decimales (con valores positivos, equivale al entero menor más cercano).
  • La segunda devuelve el entero más próximo, independientemente de si es mayor o menor que el valor original.

Gestión de errores y control de excepciones

La gestión de errores corresponde al conjunto de mecanismos que permiten identificar, controlar y responder adecuadamente a situaciones inesperadas que pueden ocurrir durante la ejecución de un programa computacional. Estos errores pueden surgir por entradas inválidas, operaciones no permitidas o fallos en la lógica implementada. En programación, resulta fundamental anticipar este tipo de situaciones para evitar interrupciones inesperadas y mejorar la robustez de los análisis, facilitando así la creación de programas más seguros, comprensibles y estables.

Podríamos estar acostumbrados a escribir números utilizando coma , como separador de decimales (p. ej. \(3,14159\ldots\)). Manipulación y procesamiento de cadenas de texto

Las cadenas de texto representan secuencias de caracteres utilizadas para almacenar y procesar información textual. Su manipulación es esencial en múltiples aplicaciones, como el análisis de datos, la validación de información, la automatización de procesos y la interacción con usuarios. El manejo de cadenas incluye, por consiguiente, operaciones como concatenación, búsqueda, reemplazo, extracción y transformación de texto. Gracias a las herramientas incorporadas en Python, es posible realizar este tipo de tareas de forma sencilla y eficiente, facilitando el procesamiento de información escrita.

Ejercicio 1

John intentó enviar un mensaje a su amigo Max para decirle que le había enviado bitcoins de regalo. Al ejecutar el programa con dicho mensaje se generó un error:

message = 'Hey pal. I've sent you some bitcoins. Check your wallet!'
print(message)
  Cell In[28], line 1
    message = 'Hey pal. I've sent you some bitcoins. Check your wallet!'
                                                                       ^
SyntaxError: unterminated string literal (detected at line 1)

SyntaxError hace referencia a que existe algún problema gramatical en el código. Recordemos que Python es un lenguaje y, como tal, tiene reglas de escritura específicas que se deben cumplir.

Identifica dónde se está generando el error y corrígelo añadiendo el carácter \ justo antes.

message = 'Hey pal. I\'ve sent you some bitcoins. Check your wallet!'
print(message)
Hey pal. I've sent you some bitcoins. Check your wallet!

En efecto, el error se presentaba porque dentro del mensaje existía una comilla, la cual en el lenguaje de Python se interpreta como la apertura o el cierre de un valor de tipo texto. Para evitar esta confusión, añadimos \, lo cual notifica a Python que “escape” de su regla predefinida. Justamente por esta razón este tipo de expresiones se conocen como caracteres de escape.

NotaOtros caracteres de escape

Si quieres saber más sobre otros caracteres de escape comunes puedes consultar esta documentación. A medida que avancemos con el aprendizaje notarás que utilizamos otros con frecuencia. Por ahora te sugiero investigar sobre lo que hacen estos dos: \n y \t.

La computadora de Max solamente permite imprimir 50 caracteres. ¿Se ajusta el mensaje corregido a esta limitación? Compruébalo mediante la función len.

length = len(message)
print(f"Longitud del mensaje: {length}")
print(f"Cumple criterio de 50 caracteres: {length <= 50}")

Cumple criterio de 50 caracteres: False

Una vez corregido y enviado el mensaje, Max respondió a John, pero la respuesta venía con los siguientes problemas:

  • Caracteres # entre todas las palabras.
  • Espacios tanto al principio como al final del mensaje.
  • Letras en mayúsculas y minúsculas de forma aleatoria.
response = "  hEY#bRO,#I#nEed#YouR#hElP#bUYiNg#bTc#tONigHt!     "

Ayuda a John a descifrar el mensaje de respuesta utilizando los métodos strip, replace y lower.

# Definir el mensaje original
response = "  hEY#bRO,#I#nEed#YouR#hElP#bUYiNg#bTc#tONigHt!     "

# Eliminar los espacios al inicio y al final del texto
response = response.strip()

# Reemplazar los "#" por espacios
response = response.replace("#", " ")

# Poner todos los caracteres en minúscula
response = response.lower()

print(response)
hey bro, i need your help buying btc tonight!
NotaFunciones vs. métodos

Funciones como print o type pueden aplicarse a variables de distintos tipos; sin embargo, los métodos no. Estos últimos son un tipo de funciones especiales que solamente se utilizan en tipologías específicas. Por ejemplo, strip, replace o lower son válidos para textos, pero NUNCA para flotantes o enteros. De esta explicación se desprende el hecho de que su sintaxis es distinta:

  • Funciones: funcion(variable, argumentos)
  • Métodos: variable.metodo(argumentos)
TipPruébalo tú mismo

Seguramente supones que, así como existe el método lower para transformar los caracteres de un texto a minúsculas, igualmente debe existir el método upper para convertirlo todo a mayúsculas. ¡Estás en lo correcto! De hecho, también podemos aplicar el método capitalize para que las frases de un texto mantengan el formato de una oración. Siéntete libre de probar estos dos casos para que te familiarices con su funcionamiento.

Creación, acceso y modificación de listas

Las listas son estructuras de datos que permiten almacenar múltiples elementos dentro de una misma variable, manteniendo un orden específico y facilitando su acceso y modificación. Estas estructuras son ampliamente utilizadas para organizar colecciones de datos y realizar operaciones repetitivas sobre conjuntos de información. En Python, las listas ofrecen gran versatilidad, ya que pueden contener diferentes tipos de datos y permiten agregar, eliminar, recorrer y transformar elementos de manera dinámica. Su comprensión es fundamental para el desarrollo de algoritmos y programas más complejos, como los que realizarás más adelante en tu aprendizaje.

TipSlicing abreviado

En Python se permite simplificar el slicing cuando uno de los índices se corresponde con el primer o el último elemento de una lista. En este sentido, el código anterior podría igualmente escribirse sin especificar el valor de 0 (primer elemento):

En este slicing se ha incorporado un tercer índice (2). El mismo corresponde al salto que se requiere entre los elementos de la lista.

NotaDivisión entera y módulo

Formalmente, la operación de división entre dos números reales \(a\) y \(b\) es aquella que genera dos resultados \(q\) y \(r\) tales que

\[ a = q \times b + r \]

El valor \(q\) se denomina cociente de la división y \(r\) corresponde al residuo.

En Python, cuando se calcula una división entera se obtiene el valor \(q\) de la división. Por su parte, para obtener el componente \(r\), el código sería:

beneficio % empleados

Esta operación se conoce como módulo entre los números \(a\) y \(b\), y su estudio genera toda un área de las matemáticas con aplicaciones diversas, conocida como aritmética modular.
